# 🎓 CampusConnect — Smart Campus Management System
## 🌌 Overview

**CampusConnect** is a visually immersive and data-structure-driven smart campus management system developed in **C++ with SFML**. The project combines advanced **Data Structures & Algorithms** with a modern animated graphical interface to simulate a real-world university ecosystem.
Unlike traditional console-based management systems, CampusConnect transforms core university operations into an interactive visual experience featuring:
- Animated campus navigation
- Smart student matchmaking
- Dynamic event timelines
- Real-time notifications
- Interactive room booking system
- Visual dashboards and analytics
- Smooth transitions and UI animations

The project emphasizes both:
- Backend efficiency through DSA
- Frontend sophistication through SFML graphics

## 🧠 Core Data Structures Used

| Adjacency List Graph | Campus map and navigation |
| Dijkstra Algorithm | Shortest path finding |
| Min Heap | Booking priority queue |
| Binary Search Tree | Event calendar management |
| Hash Tables | Student lookup and indexing |
| Trie | Autocomplete search system |
| Stack (Linked List) | Undo/Redo operations |
| Circular Queue | Notification buffer |
| Doubly Linked List | Activity log management |

## 🏛️ System Modules

## Campus Navigation System
The campus is represented as an interactive graph structure where
- Nodes represent locations/buildings
- Edges represent walkable paths
- Edge weights represent distances
### Features
- Visual campus map
- Interactive node selection
- Animated shortest-path traversal
- Dijkstra route visualization
- Real-time route rendering

## Smart Room Booking System
Students can reserve university rooms through a priority-based booking system.
### Features
- Priority queue scheduling
- Booking conflict management
- Real-time booking visualization
- Queue processing system
- Undo booking operation

## Event Management System
Campus events are stored chronologically using a Binary Search Tree.
### Features
- Chronological event ordering
- Event timeline UI
- Admin event management
- Dynamic event rendering

## Smart Search & Autocomplete
CampusConnect implements an autocomplete engine for rapid searching.
### Features
- Instant search suggestions
- Student lookup
- Location lookup
- Prefix-based recommendations


## Study Partner Recommendation Engine
The system intelligently matches students based on:
- Department
- Academic year
- Subjects
- Interests
- Free time availability
### Features
- Compatibility scoring
- Smart recommendation ranking
- Match visualization cards

## Notification System
A real-time notification center powered by a circular queue.
### Features
- Notification popups
- Activity tracking
- Queue-based message handling


## Activity Log System
Tracks all user actions within the application.
### Features
- Reverse chronological logs
- User action history
- Real-time event recording
